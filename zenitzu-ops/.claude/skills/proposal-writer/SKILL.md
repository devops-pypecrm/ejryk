# Proposal writer

1. Read `context/services.md`, `context/brand-voice.md` and `templates/proposal.md`.
2. Ask for (or extract) the client name, goal, must-haves, deadline, budget if known.
3. Fill every section of the template. Use only timelines from `context/services.md`; scale up if scope is larger and say why.
4. Price: if no pricing rule exists, write `TODO: confirm` instead of inventing a number.
5. Save to `outputs/proposals/YYYY-MM-<client>-<project>.md`.
6. End with a 3-line summary the founder can paste into WhatsApp.
