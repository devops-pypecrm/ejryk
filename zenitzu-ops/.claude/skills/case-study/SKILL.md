# Case study

1. Collect real facts: client, problem, what we built, time taken, measurable result. Never invent any of them; mark gaps `TODO: confirm`.
2. Structure: Challenge > What we did > Result (numbers first) > Quote (only if provided).
3. Under 500 words, headline states the result and the time.
4. Save to `outputs/case-studies/<client>.md`.
