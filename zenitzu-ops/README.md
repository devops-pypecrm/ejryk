# Zenitzu Ops workspace

The shared knowledge base for Zenitzu Tech Solutions: who we are, how we write, how we work, and the playbooks (skills) and roles (agents) our AI team uses.

| Folder | What lives here |
|---|---|
| `CLAUDE.md` | Project instructions + agent routing rules. Read first. |
| `context/` | Facts agents must know: brand voice, style, services, audience. |
| `templates/` | Reusable layouts: proposal, client report, blog post. |
| `sops/` | Step-by-step procedures for recurring work. |
| `.claude/skills/` | One playbook per repeatable workflow (`SKILL.md`). |
| `.claude/agents/` | Specialist roles that use the skills. |
| `outputs/` | Everything the team produces, grouped by type. |

Edit these files from the website: **Admin > Workspace**. Keep each file short and specific, and update `context/` whenever services, prices or tone change.
